# 말끔

광고 분석·차단 기능이 내장된 **유튜브 전용 안드로이드 앱**입니다.
파이어폭스 엔진(GeckoView) 위에서 모바일 유튜브를 열고, 직접 만든 광고 분석·차단 확장 프로그램을 앱 안에 넣었습니다.

## 기능

- 앱을 열면 바로 유튜브 (구글 로그인 지원 목표)
- 상단 **차단** 스위치로 광고 차단 켜기/끄기
- **기록** 버튼: 광고주·카테고리 분석 기록, 전체 차단 / 고른 종류만 차단, 광고주 차단 목록
- 카톡 등에서 유튜브 링크를 누르면 말끔으로 열기 (설정 필요, 아래 참고)

## 설치

1. 이 저장소의 **Releases**에서 최신 `Malkkeum.apk`를 폰으로 다운로드
2. 눌러서 설치 (처음이면 "출처를 알 수 없는 앱 설치" 허용)
3. 이후 새 버전은 앱을 켤 때 **자동으로 알려줘요**. "받기"를 누르면 브라우저로 APK가 받아지고, 받은 파일을 눌러 설치하면 로그인·기록이 유지됩니다. (앱 제목 'Malkkeum'을 길게 누르면 직접 확인)

## 유튜브 링크를 말끔으로 열기

설정 → 애플리케이션 → **말끔** → 기본값으로 열기 → **지원되는 링크 열기** 켜기 → 링크 추가에서 모두 체크
(유튜브 앱의 같은 메뉴에서 '지원되는 링크 열기'를 꺼야 할 수도 있어요)

## 서명 키

앱 서명 키는 `app/signing/malkkeum-release.jks.enc`에 **암호화**되어 있고,
GitHub Actions가 저장소 Secrets의 `MALKKEUM_KEYSTORE_PASSWORD`로 풀어서 서명합니다.
비밀번호가 없으면 빌드가 멈춥니다. (비밀번호를 잃어버리면 새 키를 만들고 앱을 다시 설치해야 해요)

## 구조

```
extension/                 PC 크롬용 확장 프로그램 (원본)
app/src/main/assets/ytab/  앱에 내장되는 확장 프로그램 (모바일용 수정본 + app-bridge.js)
app/src/main/java/...      안드로이드 앱 (GeckoView)
.github/workflows/         GitHub에서 APK 자동 빌드
```

광고 분석 규칙을 고칠 때는 `extension/`과 `app/src/main/assets/ytab/`의 같은 파일을 함께 고쳐주세요.
