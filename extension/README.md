# 유튜브 광고 분석·차단기

유튜브 웹에서 광고를 감지해 **광고주·카테고리를 분석**하고, **전체 차단** 또는 **고른 종류만 차단**하는 브라우저 확장 프로그램입니다.

## 동작 방식

| 단계 | 하는 일 |
|---|---|
| 0. 요청 바꾸기 (v1.1) | 영상을 요청할 때 표시를 바꿔 보내서 서버가 처음부터 광고 없는 영상을 주게 함 (uBlock Origin 2026-11 방식 참고). 막히면 다른 방법으로 자동 전환 |
| 1. 사전 제거 (전체 차단 모드) | 영상·목록 데이터가 들어올 때 광고 정보와 피드 광고 칸을 깊은 곳까지 지움. 바꿔치기한 기능은 검사해도 원래 기능처럼 보이게 숨김 |
| 2. 재생 광고 분석 | 그래도 광고가 재생되면 광고 영상 제목·채널명·광고주 버튼 문구·링크 도메인을 읽음 |
| 3. 분류 | 키워드 규칙으로 12개 카테고리(게임, 금융·보험, 쇼핑, 뷰티, 식품·배달, 교육, 앱·IT, 자동차, 여행, 건강, 부동산, 엔터) 중 하나로 분류 |
| 4. 차단 | 차단 대상이면 음소거 → 16배속 → 끝으로 이동 → 건너뛰기 버튼 클릭. 끝나면 소리·속도 원상복구 |
| 5. 배너 광고 | 홈 피드·검색·사이드바의 광고 칸도 같은 방식으로 분석해 숨김 |

## 설치 (PC 크롬 / 웨일 / 엣지)

1. 압축을 풀어 `yt-adblock` 폴더를 준비합니다.
2. 주소창에 `chrome://extensions` (웨일은 `whale://extensions`, 엣지는 `edge://extensions`) 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `yt-adblock` 폴더 선택
5. 유튜브 탭을 새로고침

## 사용법

- 툴바의 확장 아이콘을 누르면 팝업이 열립니다.
- **전체 차단**: 모든 광고 차단 + 걸러낸 광고 기록
- **고른 종류만 차단**: 카테고리 탭에서 체크한 종류, 차단 광고주 목록에 있는 광고만 건너뜀. 관심 있는 광고는 그대로 볼 수 있음
- **광고 기록** 탭에서 광고마다 `이 광고주 차단`을 누르면 다음부터 그 광고주는 차단됩니다.

## 한계

- 유튜브가 페이지 구조를 자주 바꿔서, 바뀌면 선택자(`inject.js`의 클래스 이름)를 고쳐야 할 수 있습니다.
- 사전 제거 모드에서는 광고가 아예 안 붙으므로 광고주 정보가 남지 않고 개수만 셉니다.
- 팝업의 **진단** 탭에서 영상이 열리기까지의 과정을 볼 수 있어요. 문제가 생기면 복사해서 공유하세요.
- 카테고리 분류는 키워드 규칙이라 광고주명만 있고 단서가 없으면 '기타'로 빠집니다. `classifier.js`의 단어 목록을 늘리면 정확해집니다.
- 유튜브 **앱**(안드로이드/아이폰)에는 적용되지 않습니다. 웹 브라우저 전용입니다.
